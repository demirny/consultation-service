# Сервис записи на консультации

Учебное веб-приложение для студентов и преподавателей. Студенты фильтруют расписание по предмету и преподавателю, занимают свободное место и отменяют запись в личном кабинете. Преподаватели создают, редактируют и удаляют свои консультации, видят список студентов и меняют статусы их записей.

## Стек и требования

- Node.js 22.13+ или 24 LTS, npm и Git.
- Next.js 15 (App Router), React, TypeScript, Tailwind CSS.
- Prisma 6 и SQLite. Схема и миграции находятся в `prisma/`.
- JWT в HTTP-only cookie, подпись через jose, пароли хешируются bcryptjs.
- Общие схемы Zod для форм и API, интерфейс и сообщения об ошибках на русском.

## Локальный запуск

Подставьте адрес Git-репозитория. Для копии из сдаваемой папки можно указать её полный путь вместо URL.

```bash
git clone -b develop <URL-или-путь-к-репозиторию> college-consultations
cd college-consultations
npm install
cp .env.example .env
npx prisma migrate dev
npm run db:seed
npm run dev
```

В PowerShell скопируйте окружение командой `Copy-Item .env.example .env`. Если репозиторий уже открыт, начните с `npm install`.

Откройте [http://localhost:3000](http://localhost:3000). `DATABASE_URL="file:./dev.db"` указывает на `prisma/dev.db` относительно схемы. В ветке уже есть мигрированная и заполненная учебная база. `npm run db:seed` заменяет все данные учебным набором и создаёт консультации на ближайшие дни.

Для запуска вне учебного окружения задайте случайный `SESSION_SECRET`, используйте HTTPS и чистую базу без тестовых аккаунтов. Регистрация преподавателя через форму открыта по условиям учебного задания.

## API

| Метод и маршрут | Доступ и действие |
| --- | --- |
| `POST /api/auth/register`, `/api/auth/login`, `/api/auth/logout` | Регистрация, вход и выход |
| `GET /api/consultations?teacherId=&subject=` | Публичное расписание, число свободных мест и варианты фильтров |
| `POST /api/consultations` | Создать консультацию от имени преподавателя |
| `PATCH /api/consultations/:id` | Изменить поля своей консультации |
| `DELETE /api/consultations/:id` | Удалить свою консультацию и связанные записи |
| `GET /api/bookings` | Записи студента или записи на консультации преподавателя |
| `POST /api/bookings` | Записаться с телом `{ "consultationId": "…" }` |
| `PATCH /api/bookings/:id` | Изменить `status` своей записи на `CANCELLED` либо управлять статусом записи на свою консультацию |
| `DELETE /api/bookings/:id` | Отменить свою запись студента |

Поля консультации при создании включают `title`, `description`, `subject`, `date` в формате `ГГГГ-ММ-ДД`, `startTime` и `endTime` в формате `ЧЧ:ММ`, `location` и целое число `maxStudents`. Дата и время относятся к местному расписанию организации.

Занятые места считаются по статусу `CONFIRMED`. При повторной записи после отмены восстанавливается существующая строка. Уникальный индекс пары «консультация и студент» защищает от дублей, а транзакции сохраняют лимит мест при конкурентных запросах.
